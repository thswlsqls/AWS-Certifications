# 기타 서비스

> 배점은 낮지만 이름·용도 매칭으로 출제되는 서비스들.

## 개요

각각 따로 한 단원을 차지할 만큼은 아니지만 시험에 한 문제씩 나오는 서비스 모음. 깊게 파기보다 **"이런 상황이면 이 서비스"**라는 매칭을 기억하는 게 목적이다. 강의의 "Other Services" 단원에 모여 있고, DVA·CloudOps 양쪽에 걸친다.

## 개발 관점 (DVA) #dva

![[AWS Certified Developer Slides v44.pdf#page=877]]

### Amazon SES — 이메일 전송

대규모로 이메일을 보내는 완전관리형 서비스. **수신·발신 둘 다** 가능하고, 평판 대시보드와 스팸 피드백, 전송·반송(bounce)·열람 같은 통계를 준다. **DKIM·SPF**(발신자 인증)를 지원하고, 공유·전용·고객 소유 IP를 고를 수 있다. 콘솔·API·**SMTP**로 보낸다. 용도는 거래 알림(transactional)·마케팅·대량 메일.

### Amazon OpenSearch — 무엇이든 검색

ElasticSearch의 후속. DynamoDB는 **기본 키나 인덱스로만** 조회하지만, OpenSearch는 **어떤 필드든, 부분 일치까지** 검색한다. 그래서 다른 DB를 **보완하는 검색 엔진**으로 흔히 붙인다.

- 두 모드: managed cluster / serverless cluster. **SQL은 기본 미지원**(플러그인으로 가능). 보안은 Cognito·IAM·KMS·TLS, 시각화는 OpenSearch Dashboards.
- **수집 패턴**(출제됨):
  - **DynamoDB**: 테이블 변경 → **DynamoDB Stream → Lambda → OpenSearch**. 항목 조회는 DynamoDB, 검색은 OpenSearch로 나눠 쓴다.
  - **CloudWatch Logs**: Subscription Filter → **Lambda(실시간)** 또는 **Kinesis Data Firehose(준실시간)** → OpenSearch.
  - **Kinesis**: Data Streams → **Firehose(준실시간, Lambda로 변환)** → OpenSearch, 또는 Streams → **Lambda(실시간)** → OpenSearch.

### Amazon Athena — S3를 SQL로

**S3에 있는 데이터를 표준 SQL로 분석**하는 **서버리스** 쿼리 서비스(Presto 기반). CSV·JSON·ORC·Avro·Parquet 지원. 과금은 **스캔한 데이터 1TB당 $5**. **QuickSight**와 묶어 리포팅·대시보드를 만든다. VPC Flow Logs·ELB Logs·CloudTrail 분석에 자주 쓴다. → **"S3 데이터를 서버리스 SQL로 분석"이면 Athena.**

- **성능·비용 줄이기**: **컬럼형(Parquet·ORC)** 으로 두면 스캔이 줄어 싸고 빠르다(Glue로 변환). 데이터 **압축**, S3 **파티셔닝**(가상 컬럼으로 쿼리), **큰 파일(>128MB)** 로 오버헤드 줄이기.
- **Federated Query**: 관계형·비관계형·객체·커스텀 소스(AWS·온프레미스)에 걸쳐 SQL. **Lambda에서 도는 Data Source Connector**(CloudWatch Logs·DynamoDB·RDS 등)를 쓰고, 결과는 S3에 저장.

### Amazon MSK — 관리형 Kafka

**Kinesis의 대안**으로, AWS가 관리하는 Apache Kafka. broker·Zookeeper 노드를 대신 만들고, **VPC 안에 multi-AZ(최대 3)** 로 배포하며, 흔한 Kafka 장애에서 자동 복구한다. 데이터는 **EBS에 원하는 만큼** 보관. 용량 관리가 싫으면 **MSK Serverless**.

- **Kinesis Data Streams vs MSK**: KDS는 메시지 **1MB 제한**, Shard(splitting·merging), TLS in-flight. MSK는 1MB 기본이지만 **더 크게 설정 가능(예: 10MB)**, Topic + Partition(**파티션 추가만** 됨, 줄이기 불가), **PLAINTEXT 또는 TLS** in-flight. 둘 다 KMS at-rest 암호화.
- **MSK 소비자**: Kinesis Data Analytics for Apache Flink, Glue Streaming ETL(Spark Streaming), Lambda, EC2·ECS·EKS 위의 앱.

### 보안·설정 4종 (이름 ↔ 용도)

- **AWS Certificate Manager (ACM)**: SSL/TLS 인증서를 프로비저닝·관리·배포해 웹사이트 **HTTPS(in-flight 암호화)** 를 제공. public·private 둘 다, **public TLS는 무료**, **자동 갱신**. **ELB·CloudFront·API Gateway**에 붙는다.
- **AWS Private CA**: 프라이빗 인증 기관(root·subordinate)을 만들어 X.509 인증서를 발급. **조직 내부에서만 신뢰**(공개 인터넷 아님). ACM 통합 서비스에서 동작. 용도는 내부 TLS·코드 서명·사용자/기기/API/IoT 인증, 사내 PKI 구축.
- **AWS Macie**: ML·패턴 매칭으로 S3의 **민감 데이터(PII)를 찾아 알린다.** S3 분석 → 알림 → EventBridge 연동.
- **AWS AppConfig**: **동적 설정을 코드 배포와 분리**해 구성·검증·배포(앱 재시작 없이). feature flags·앱 튜닝·allow/block list에 쓴다. 점진 배포 후 문제가 생기면 롤백. 배포 전 검증은 **JSON Schema(구문 검사)** 또는 **Lambda(의미 검사)**. EC2·Lambda·ECS·EKS에서 사용.

## 시험 함정

- **S3 데이터를 서버리스 SQL로 분석/리포팅** → **Athena**(+QuickSight). 비용↓는 Parquet·ORC·압축·파티셔닝 #exam/trap/others
- **어떤 필드든·부분 일치 검색**, 다른 DB 보완 → **OpenSearch**. DynamoDB는 PK/인덱스로만 조회 #exam/trap/others
- DynamoDB 항목을 검색 가능하게 → **DynamoDB Stream → Lambda → OpenSearch** #exam/trap/others
- **대량·거래 이메일 전송**(DKIM·SPF, SMTP) → **SES** #exam/trap/others
- **관리형 Apache Kafka** → **MSK**. KDS(1MB 고정·Shard)와 달리 **메시지 더 크게(예 10MB)**, Topic·Partition(추가만 가능) #exam/trap/others
- **HTTPS용 SSL/TLS 인증서**(ELB·CloudFront·API Gateway, public 무료·자동 갱신) → **ACM**. 조직 내부 전용 인증서 → **Private CA** #exam/trap/others
- **S3의 민감정보(PII) 탐지** → **Macie** #exam/trap/others
- **코드 배포와 분리된 동적 설정·feature flag**(재시작 없이, JSON Schema/Lambda 검증) → **AppConfig** #exam/trap/others
