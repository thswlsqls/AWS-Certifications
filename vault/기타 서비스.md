# 기타 서비스

> 배점은 낮지만 이름·용도 매칭으로 출제되는 서비스들.

## 개요

강의 끝의 "Other Services" 단원에 묶여 나오는 서비스 모음이다. 배점이 큰 핵심 서비스(S3·EC2·Lambda 등)와 달리, 여기 담긴 것들은 **이름과 용도만 매칭하면 풀리는** 수준으로 짧게 나온다. 시험별로 다루는 목록이 조금씩 달라서, 각 관점 섹션에 그 시험에서 나온 서비스만 정리한다.

이미 전용 노트가 있는 서비스(SQS·SNS·ECS·EKS·X-Ray 등)는 그 노트에서 깊게 보고, 이 노트에는 **전용 노트가 따로 없는 작은 서비스**를 담는다.

## 운영 관점 (CloudOps) #cloudops

![[AWS Certified CloudOps Engineer Associate Slides v41.pdf#page=672]]

CloudOps의 "Other Services" 단원은 대부분 이미 배운 서비스를 운영 관점에서 다시 짚는 복습이다. 그중 **전용 노트가 없어 여기서만 다루는** 새 서비스는 모니터링 SaaS 두 개(Grafana·Prometheus)와 자원 공유 서비스(RAM)다. 나머지(SQS·SNS·ECS·EKS·X-Ray)는 전용 노트로 갈음하고, CloudOps에서만 새로 강조된 운영 포인트만 아래에 한 줄씩 남긴다.

### Amazon Managed Service for Grafana

관리형 Grafana. 지표·로그·트레이스를 한 대시보드에서 본다. **Workspace** 단위로 대시보드를 만들고, 프로비저닝·확장·유지보수는 AWS가 맡는다. CloudWatch·Managed Prometheus·X-Ray·OpenSearch는 물론 Prometheus·Datadog 같은 외부/오픈소스 데이터 소스도 붙는다. "여러 출처의 지표를 한 화면에 시각화" 시나리오의 답.

### Amazon Managed Service for Prometheus

관리형 Prometheus. **컨테이너 지표** 모니터링용 서버리스 서비스다. 수집·저장·쿼리를 자동 확장하고 데이터를 **3개 AZ에 복제**한다. 오픈소스 그대로 **PromQL**로 조회하고, **EKS·자체 관리 Kubernetes**와 함께 쓴다. 보관 기간은 기본 150일, 최대 3년. 보통 **Prometheus로 수집 → Grafana로 시각화** 짝으로 나온다.

### AWS Resource Access Manager (RAM)

내가 가진 자원을 **다른 계정이나 같은 Organization과 공유**해 중복 생성을 피한다. 공유 가능한 대표 자원: **VPC Subnet, Transit Gateway, Route 53 Resolver Rule, License Manager 설정**.
- **VPC Subnet 공유**: 여러 계정의 자원을 **같은 서브넷**에 띄운다(같은 Organization이어야 함). 단 **Security Group과 기본 VPC는 공유 불가.** 참가 계정은 자기 자원만 관리하고 남의 자원은 보거나 못 고친다. 같은 서브넷이라 **사설 IP로 계정 간 통신**이 되고, 다른 계정의 SG를 참조할 수도 있다.

### 복습 서비스의 CloudOps 운영 포인트 (전용 노트 참고)

이미 배운 서비스 중 운영 시험이 새로 강조한 부분만 짚는다. 상세는 각 전용 노트에 있다.
- **[[SQS & SNS & Kinesis|SQS]]**: Visibility Timeout(폴링되면 다른 소비자에게 안 보임, 기본 30초), Dead Letter Queue(MaximumReceives 초과 시 이동), Message Retention(1분~14일, 기본 4일), Access Policy(리소스 기반 정책).
- **[[컨테이너 서비스|ECS]]**: Fargate 임시 스토리지(20~200GB, AES-256), **FireLens**(Fluent Bit/Fluentd 사이드카로 로그를 CloudWatch·외부로 라우팅).
- **[[컨테이너 서비스|EKS]]**: Control Plane 로깅(api·audit 등 종류별로 CloudWatch로), **EKS Cluster Insights**(Config·Upgrade Insights로 업그레이드 전 문제 진단), 오토스케일링 모드(Cluster AutoScaler=같은 크기 노드 증감 / **Karpenter**=적정 크기 자원을 1분 내 투입 / EKS Auto Mode).
- **[[CloudWatch & CloudTrail & Config|X-Ray]]**: 분산 추적으로 병목·의존성·에러를 시각화. ECS 연동은 **X-Ray 데몬 컨테이너**(EC2형) 또는 **사이드카**(Fargate형)로 붙인다.

## 시험 함정

- 컨테이너 지표 수집은 **Managed Prometheus**(PromQL), 시각화는 **Managed Grafana** — 보통 짝으로 쓴다. #exam/trap/others
- 여러 출처 지표를 한 대시보드에 → **Managed Grafana**(Workspace 단위). #exam/trap/others
- 계정 간 자원 공유는 **RAM**. VPC Subnet은 공유되지만 **Security Group과 기본 VPC는 공유 불가**, 같은 Organization이어야 한다. #exam/trap/others
