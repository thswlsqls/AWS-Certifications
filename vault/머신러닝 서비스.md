# 머신러닝 서비스

> ML 서비스 한 줄 정의 암기 — 이름과 용도 매칭 문제가 대부분.

## 개요

AWS의 관리형 AI/ML 서비스 모음. 모델을 직접 만들지 않고 API만 호출해 쓰는 **완성형 서비스**(Rekognition·Transcribe·Polly 등)와, 직접 모델을 만드는 **SageMaker**로 나뉜다. SAA에서는 깊은 원리가 아니라 **"이 시나리오엔 어느 서비스?"** 한 줄 매칭이 거의 전부다. 입력·출력이 무엇인지(이미지/음성/텍스트 → 무엇)로 외우면 헷갈리지 않는다.

### 한 줄 정의 (매칭용)

- **Rekognition** — 이미지·비디오에서 객체·사람·텍스트·장면을 찾는다. 얼굴 탐지·분석·검색(사용자 인증, 인원 수 세기), 유명인 인식, 콘텐츠 검열.
- **Transcribe** — 음성 → 텍스트 (ASR). 예: 통화 전사, 자막.
- **Polly** — 텍스트 → 음성. 말하는 앱을 만든다. (Transcribe와 방향 반대.)
- **Translate** — 언어 번역. 웹사이트·앱 현지화.
- **Lex** — 음성·텍스트의 **의도(intent)**를 인식해 챗봇·콜센터 봇을 만든다 (Alexa와 같은 기술, ASR + 자연어 이해).
- **Connect** — 클라우드 기반 가상 콘택트 센터(통화 수신, 컨택트 플로우). 선결제 없고 기존 대비 약 80% 저렴.
- **Comprehend** — 자연어 처리(NLP). 텍스트에서 언어·핵심 구절·인물·브랜드·감정(긍정/부정)을 뽑고 주제별로 묶는다.
- **Comprehend Medical** — 비정형 임상 문서(의사 메모·퇴원 요약 등)에서 정보 추출, **PHI(보호 대상 건강정보) 탐지(DetectPHI API)**.
- **SageMaker** — 개발자·데이터 과학자가 ML 모델을 **직접** 만들고 학습·배포하는 완전관리형 플랫폼. (완성형 API가 아니라 모델 개발 도구.)
- **Kendra** — ML 기반 **문서 검색**. 여러 문서(text·PDF·HTML·PPT·Word·FAQ) 안에서 자연어 질문에 답을 추출. 사내 지식 검색.
- **Personalize** — 실시간 **개인화 추천**(Amazon.com과 같은 기술). 제품 추천·재정렬, 맞춤 마케팅.
- **Textract** — 스캔 문서·이미지·PDF에서 텍스트·손글씨·**폼·표 데이터**를 추출. 예: 인보이스, 의료 기록, 신분증·여권.

### 시험에서 갈리는 지점

- **음성↔텍스트 방향**: 음성을 글로 → **Transcribe**, 글을 말로 → **Polly**.
- **챗봇 vs 콜센터**: 대화 의도를 알아듣는 봇 자체 → **Lex**, 전화를 받는 콘택트 센터 인프라 → **Connect**. (둘을 합쳐 "전화로 예약" 흐름: Connect로 통화 수신 → Lex로 의도 인식 → Lambda → CRM.)
- **일반 텍스트 vs 의료 텍스트**: 보통 NLP → **Comprehend**, 임상 문서·PHI → **Comprehend Medical**.
- **검색 vs 추천**: 문서에서 답을 찾기 → **Kendra**, 사용자에게 다음에 살 것을 제안 → **Personalize**.
- **문서에서 글자 추출 vs 이미지 내용 인식**: 스캔 문서·폼·표의 텍스트를 구조화해 뽑기 → **Textract**, 사진·영상 속 객체·얼굴·장면 인식 → **Rekognition**. (Rekognition도 텍스트 탐지를 하지만, 양식·표의 키-값 추출은 Textract.)
- **Rekognition 콘텐츠 검열**: 플래그 기준인 **Minimum Confidence Threshold**를 설정하고, 민감 항목은 **Amazon A2I(Augmented AI)**로 사람이 다시 검토하게 보낸다.
- **PII/PHI 자동 제거**: 통화·문서에서 개인정보를 지우는 시나리오 → Transcribe의 **Redaction**(PII), Comprehend Medical의 **PHI 탐지**.

## 시험 함정

- 음성→텍스트는 Transcribe, 텍스트→음성은 Polly. 방향을 바꿔 묻는다. #exam/trap/ml
- 챗봇 봇 자체는 Lex, 전화 받는 콘택트 센터는 Connect. #exam/trap/ml
- 의료·임상 텍스트와 PHI는 Comprehend Medical(DetectPHI), 일반 NLP는 Comprehend. #exam/trap/ml
- 문서에서 답 검색은 Kendra, 사용자 추천은 Personalize. #exam/trap/ml
- 양식·표가 있는 스캔 문서의 데이터 추출은 Textract, 사진·영상 속 인식은 Rekognition. #exam/trap/ml
- 모델을 직접 만들면 SageMaker, API만 호출하면 완성형 서비스(Rekognition·Comprehend 등). #exam/trap/ml
- Rekognition 콘텐츠 검열은 Minimum Confidence Threshold + A2I 수동 검토. #exam/trap/ml
